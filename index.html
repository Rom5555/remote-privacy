Privacy Policy — Remote

Effective date: 25 October 2026

Remote is a local-first TV remote application published by Rom5555.

Data collection and sharing

Remote does not create user accounts and does not send analytics, advertising identifiers, TV details, or usage data to the developer.

Remote does not sell or share user data with advertisers or data brokers.

Local network and nearby-device access

Remote uses the phone's local network to discover and control compatible televisions.

To provide this feature, the app may access:

  • the TV name and model;
  • the TV's local IP address;
  • the TV's local network MAC address when available, for Wake-on-LAN;
  • local network discovery responses;
  • Samsung remote-control authorization tokens.

These values are used only to discover, reconnect to, wake, and control televisions.

Network communication for remote-control features is between the phone and the television on the local network. Remote does not send these values to a developer-operated server.

Android permissions

On recent Android versions, Remote may request Nearby devices permission to establish or use a direct local Wi-Fi connection after the user taps Wi-Fi Direct.

On Android 12 and earlier, Android may require location permission for Wi-Fi discovery APIs. Remote does not read, store, or transmit the user's physical location.

Local storage and security

Remembered TV details are stored in app-private local storage on the device.

Samsung authorization tokens and remembered approval for legacy tokenless TVs are stored using the operating system's secure storage facilities. They are excluded from Android cloud backup and device-to-device transfer. Non-secret TV records may be included in the Android backup selected by the user. A restored record must be verified again before its authorization is reused.

When the home network is unavailable, Remote can create a Wi-Fi Direct group with the TV. The group name and passphrase are generated on the phone, stored in app-private storage and excluded from Android cloud backup and device-to-device transfer.

Samsung self-signed TLS certificates are accepted for device compatibility. Use a trusted local network: this does not provide strong cryptographic identification of a TV.

Debug builds can record bounded local diagnostic traces. Sensitive fields, including numeric tokens, are redacted; free-form strings are masked without a stable hash. Network metadata and remote navigation may remain visible. Traces are not uploaded automatically; review a report before sharing it.

Retention and deletion

Local app data is retained until it is replaced by newer local TV information, the app's storage is cleared, or Remote is uninstalled.

Remote has no server-side account or server-side user profile to delete.

Children

Remote is a general-purpose utility and is not designed to collect personal information from children.

Changes

If Remote's data practices change, this policy will be updated before the changed behavior is distributed.

Contact

For privacy questions, use the developer support contact published with Remote on its Google Play listing.
